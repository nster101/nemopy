## PROJECT CONTEXT (fill this in)

The crew personas are project-agnostic; this block is the only project-specific
context they read on every session. Replace the placeholders below.

- **Direction / mandate:** _what this project is and where it is going._
- **Off-limits / sensitive files:** _paths the crew must not edit without explicit
  human sign-off._
- **Build / test / lint commands:** _e.g. `npm test`, `make check`. Also add these to
  `.claude/settings.json` → `permissions.allow` (e.g. `"Bash(npm test:*)"`) so the
  crew can run them without a prompt._
- **Conventions:** _naming, layout, and anything a builder must follow._
